# VNBrokers Connector

This repository contains native plugins that connect VNBrokers' market data and
trading services to popular trading and charting platforms, including:

- **AmiBroker** – data feed plugin (see [`amibroker/`](amibroker/))
- **Qt5 / Qt Trading** – planned
- ...
